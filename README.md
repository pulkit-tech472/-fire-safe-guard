# Fire Safety App 🔥🚒

A simple and responsive web application built using HTML & CSS to spread awareness about fire safety, prevention tips, and emergency response guidelines.

## Features
- 📋 Fire safety tips and do's & don'ts
- 🚨 Emergency contact numbers / helpline info
- 🧯 Guide on using fire extinguishers
- 🏢 Evacuation procedures and safety measures
- 📱 Fully responsive design (mobile & desktop friendly)
- 🎨 Clean and user-friendly UI

## Tech Stack
- HTML5
- CSS3
- JavaScript

## How to Run

git clone https://github.com/your-username/fire-safety-app.git
cd fire-safety-app.
